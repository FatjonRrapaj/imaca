# IMACA

Single-page website for IMACA, built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Files

- `index.html` — page markup
- `privacy.html`, `terms.html` — legal pages (same header, footer and styles)
- `styles.css` — design tokens and layout
- `script.js` — mobile menu toggle
- `assets/` — photos

## Development

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```
